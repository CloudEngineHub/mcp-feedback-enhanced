### 🏗️ 架構概覽

MCP Feedback Enhanced 採用**單一活躍會話 + 持久化 Web UI**的創新架構，達成 AI 助手與使用者之間的無縫互動體驗。

#### 核心特性
- **環境適應**: WSL 中改用 Windows 瀏覽器開啟介面；SSH 等遠端環境只偵測並寫進除錯日誌，需自行設定連接埠轉送
- **單一活躍會話**: 替代傳統多會話管理，提升效能和使用者體驗
- **持久化 Web UI**: 支援多次循環呼叫，無需重複開啟瀏覽器
- **即時雙向通訊**: WebSocket 實作前後端狀態同步
- **智慧資源管理**: 自動清理和會話生命週期管理
- **提示詞管理系統**: 常用提示詞的 CRUD 操作和快速選擇
- **自動提交功能**: 倒數計時器和自動回饋提交機制
- **會話管理功能**: 會話歷史追蹤和統計分析（v2.4.3 重構增強）
- **音效通知系統**: 智慧音效提醒和自訂音效管理（v2.4.3 新增）
- **智慧記憶功能**: 輸入框高度記憶和一鍵複製（v2.4.3 新增）
- **多語言支援**: 繁體中文、簡體中文、英文動態切換

#### 技術棧
- **後端**: Python 3.11+, FastAPI, FastMCP
- **前端**: HTML5, JavaScript ES6+, WebSocket, Web Audio API（v2.4.3）
- **通訊**: WebSocket, HTTP REST API
- **儲存**: 伺服器端 `~/.config/mcp-feedback-enhanced/`：`ui_settings.json`（設定、介面語言、提示詞、自訂音效、輸入框高度）、`session_history.json`（會話歷史）；瀏覽器 localStorage 只存通知設定
- **部署**: uvicorn, 跨平台支援
- **桌面模式**: `MCP_DESKTOP_MODE=true` 時以 Tauri 桌面殼載入同一個 Web 介面

### 🆕 v2.4.3 版本亮點

#### 🔊 音效通知系統
- **內建音效**: 經典提示音、通知鈴聲、輕柔鐘聲
- **自訂音效**: 支援 MP3、WAV、OGG 格式上傳
- **智慧播放**: 會話更新時自動播放通知音效
- **音量控制**: 0-100% 可調節音量
- **瀏覽器相容**: 處理自動播放政策限制

#### 📋 會話管理重構
- **頁籤化設計**: 從側邊欄遷移到獨立頁籤，解決瀏覽器相容性問題
- **伺服器端歷史儲存**: 存在 `session_history.json`，儲存期限可選 24、72、168、720 小時（預設 72）
- **隱私控制**: 三級使用者訊息記錄設定（完整記錄/基本統計/停用記錄）
- **資料管理**: 匯出和清理功能
- **詳情查看**: 專門的會話詳情彈出視窗

#### 🧠 智慧記憶功能
- **輸入框高度記憶**: 自動儲存和恢復輸入框高度
- **一鍵複製**: 專案路徑和會話ID點選複製
- **設定持久化**: 使用者偏好自動儲存
- **國際化支援**: 複製提示支援多語言
